# chicago-reuse-detergent
Project to demonstrate reuse and the cost and environmental benefits of switching from single use to reuse for a specific product (laundry detergent) in Chicago


### Project Structure
├── data/               # Raw and Cleaned CSVs (Git-ignored)
├── sql/                # PostgreSQL schema and business logic
├── scripts/            # Standalone Python scripts for the data pipeline
├── notebooks/          # Exploratory analysis and Tipping Point modeling
├── visuals/            # Exported Tableau Dashboards and Impact charts
└── README.md           # Executive Summary and Project Guide
